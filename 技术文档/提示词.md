## 学习命令行工具


要让 DeepSeek 的输出更适合“学习 Linux 命令行工具”，提示词的关键不是简单问“fdisk 怎么用”，而是把**角色、水平、学习目标、输出结构、安全边界、练习方式**都说清楚。下面给你一套可直接套用的方法。

---

## 1. 提示词设计原则

写提示词时尽量包含这 7 类信息：

1. **角色**：让模型扮演 Linux 讲师/运维工程师。
2. **我的水平**：初学者、会基本命令、还是备考 LPIC。
3. **学习目标**：理解概念、会看输出、会安全操作、能排错。
4. **输出结构**：按“概念→命令→参数→示例→风险→练习→自测”组织。
5. **环境约束**：如 Ubuntu/CentOS、虚拟机、是否允许危险操作。
6. **安全要求**：区分只读命令和破坏性命令，危险操作必须警告并给替代练习方式。
7. **互动方式**：每轮只讲一个模块，讲完出题，等我回答再继续。

---

## 2. 通用提示词模板

可以直接复制：

```text
你是一位耐心的 Linux 命令行讲师，擅长把命令讲得可操作、可验证、可排错。

我想学习命令：fdisk
我的水平：Linux 初学者，会 cd/ls/cat/sudo 等基础命令，但对磁盘分区不熟。

1. 理解这个命令解决什么问题；
2. 能读懂它的典型输出；
3. 掌握常用参数和交互式操作；
4. 知道哪些操作危险、如何避免误操作；
5. 能通过练习题巩固。

请按以下结构输出，不要一次性堆太多内容：
A. 一句话定义和适用场景

要求：
- 命令用代码块；
- 每个参数都解释；
- 标注“只读/有风险/破坏性”；
- 不要编造不存在的参数；
- 不确定的地方明确说不确定；
- 对 fdisk 的分区表修改、写盘、删除分区等操作必须强调备份和确认设备名。
```

## 3. 针对 fdisk 的更具体提示词

fdisk 涉及分区表，学习时最怕误操作。建议先要求“只读学习”，再进入模拟练习：

```text
请以“安全学习 fdisk”为目标，带我分 5 轮学习：

第 1 轮：讲清 MBR/GPT、分区、块设备、/dev/sda 等概念，只讲概念不操作。
第 2 轮：只讲只读命令，如 fdisk -l、lsblk、blkid、parted -l，并解释输出字段。
第 3 轮：用虚拟磁盘或 loop 设备演示 fdisk 交互界面，逐项解释 m/n/p/d/w/q 等按键含义。
第 4 轮：给一个完整但安全的练习流程：创建虚拟磁盘镜像→losetup→fdisk 分区→查看结果→清理。
第 5 轮：出 5 道排错/判断题，检查我是否理解“设备名、分区表、写盘、同步、挂载”等风险点。

每轮结束先出 2 道小题让我回答，不要直接进入下一轮。
所有危险命令必须加“⚠️破坏性操作”标记，并说明为什么危险、如何确认设备名。
```

## 4. 多轮追问模板

不要一次让模型讲完，采用“模块化追问”效果更好。

### 第一轮：概念和输出

```text
请只讲 fdisk -l 的输出。逐字段解释，假设我是初学者。用一个虚拟示例输出说明，不要给修改分区的命令。
```

### 第二轮：参数拆解

```text
请把 fdisk 常用参数做成表格：参数、作用、是否只读、风险等级、典型示例。只列真实存在的常见参数。
```

### 第三轮：交互式操作

```text
请模拟 fdisk /dev/vdb 的交互过程，解释每个按键：m、p、n、d、t、w、q。用“我输入什么→屏幕显示什么→含义是什么”的格式。
```

### 第四轮：安全练习

```text
请设计一个在 Ubuntu 虚拟机中用 loop 设备练习 fdisk 的完整步骤，要求不碰真实系统盘。每一步说明目的和验证方法，最后给出清理步骤。
```

### 第五轮：排错和自测

```text
请出 8 道 fdisk 学习自测题，包含概念题、输出阅读题、危险操作判断题。先不给答案，等我作答后再批改并解释。
```

## 6. fdisk 学习时特别要问的问题

建议把这些加入提示词或后续追问：

- `fdisk -l` 输出中的 `Disk /dev/sda`、`Sector size`、`Disklabel type`、`Device`、`Boot`、`Start`、`End`、`Sectors`、`Size`、`Type` 分别是什么意思？
- MBR 和 GPT 有什么区别？fdisk 如何体现？
- `n` 新建分区时，主分区、扩展分区、逻辑分区怎么选？
- `w` 和 `q` 的区别是什么？为什么 `q` 更安全？
- 修改分区表后为什么要 `partprobe` 或 `udevadm settle`？
- 分区和文件系统有什么区别？为什么 fdisk 分区后还要 `mkfs`？
- 删除分区、修改分区类型、写盘分别有什么风险？
- 如何确认自己操作的是测试盘而不是系统盘？
- `lsblk`、`blkid`、`df -h`、`mount` 如何配合验证？
- 在虚拟机中如何添加一块测试磁盘或用 loop 镜像练习？

## 7. 推荐的学习提示词组合

最实用的组合是：

```text
你是我的 Linux 命令行教练。我要学习 fdisk，水平是初学者，环境是 Ubuntu 虚拟机。
请采用“只读先行、虚拟盘练习、每轮小测”的方式教学。
每轮输出结构：概念→常用命令→参数解释→安全示例→风险提示→练习→等我回答。
危险操作必须标记 ⚠️，并说明如何确认设备名和备份。
第一轮请先讲 fdisk 是什么、适合什么场景，以及它和 lsblk/parted/mkfs 的关系，不要给任何修改分区的命令。
```

然后根据回答继续追问：

```text
请继续第二轮：只讲 fdisk -l 的输出阅读，用虚拟示例逐字段解释。
```

```text
请继续第三轮：在 loop 设备上设计一个安全的 fdisk 练习，包含创建、查看、清理。
```

## 8. 注意事项

- **不要让模型直接给你在真实磁盘上执行的“删除/写盘”命令**，除非你明确在虚拟机测试盘上操作。
- 要求模型**区分只读命令和破坏性命令**。
- 要求模型**不要编造参数**，不确定就说不确定。
- 学习 fdisk 最好配合 `lsblk`、`blkid`、`df -h`、`mount`、`parted` 一起理解。
- 最安全练习方式是：虚拟机加一块空磁盘，或用 `dd` 创建镜像文件后通过 `losetup` 练习。

一句话总结：**提示词要写成“学习任务书”，而不是“命令查询”。明确角色、水平、结构、安全边界和互动测验，DeepSeek 的输出就会从“百科式说明”变成“可操作教程”。**
