## 电源线

### C13和C14

**C13 和 C14 是 IEC 60320 标准中一对配套使用、性能参数基本相同的电源接口**，可以理解为“**C13 是母头（输出端），C14 是公头（输入端）**”。C14 公头插在设备（如服务器电源、PDU）的插座上，C13 母头则连接电源线。

#### 核心性能参数

两者的电气和温度额定值在标准层面是一致的。

| 参数项 | **C13 连接器（母头/输出）** | **C14 输入口（公头/设备端）** |
| :--- | :--- | :--- |
| **国际额定电流/电压** | **10A / 250V AC** | **10A / 250V AC** |
| **北美额定电流/电压** | **15A / 250V AC** | **15A / 250V AC** |
| **最高工作温度** | **70°C** | **70°C** |
| **针脚配置** | **2 个电源针脚 + 1 个接地针脚**（2P+E） | 同左 |
| **标准归属** | IEC 60320（具体为 C13 连接器） | IEC 60320（具体为 C14 输入口） |

补充说明：部分产品数据表会将工作温度范围标为 **-25°C 至 +70°C**，但最关键的持续工作上限仍是 **70°C**。在北美，有时会利用 15A 的额定值，但这依赖于线缆和整个供电回路的匹配，**国际通用基准仍是 10A**。

#### IDC 运维中的关键注意点

**参数相同，角色不同**：虽然 C13 和 C14 的参数表一样，但它们是公母配对关系，**功能不可互换**。给服务器供电时，C14 端连接服务器电源或 PDU 的输出口，C13 端则连接电源线的另一端（或 PDU 的输入口）。

**警惕“C13/C14 标称，但电流更低”的线缆**：连接器的额定值是 **10A**，但整根电源线的实际安全载流量还取决于**线径（AWG）**。例如，部分 18AWG 的成品线缆可能仅被认证为 10A 或更低，而 16AWG 线缆才更能稳定承载 10A 电流。**不能仅看接口是 C13/C14 就默认为整线支持 10A**。

**与 C19/C20 的区分**：C13/C14 是 **10A/16A 以下**设备（如大多数 1U/2U 服务器）的标准接口。更高功率的设备（如大型交换机、刀片机框）会使用更大的 **C19/C20** 接口，其国际额定值为 **16A/250VAC**，北美可达 **20A**，不可混用。

**温度余量**：70°C 是连接器触点附近的允许环境温度上限。在 IDC 高密度机柜中，如果热通道温度过高，或电源线被捆扎在发热设备附近，实际工况温度可能接近此限值，需在容量规划和理线时预留余量。

### C19和C20

**C19 和 C20 是 IEC 60320 标准中一对配套使用、性能参数基本相同的电源接口**，与 C13/C14 的关系完全类似：**C19 是母头（电缆连接器），C20 是公头（设备输入口）**。C20 公头插在服务器电源或 PDU 的 C20 插座上，C19 母头则连接电源线的另一端。

#### 核心性能参数

两者的电气和温度额定值在标准层面一致，但北美存在一个更高的电流档位。

| 参数项 | **C19 连接器（母头/输出）** | **C20 输入口（公头/设备端）** |
| :--- | :--- | :--- |
| **国际额定电流/电压** | **16A / 250V AC** | **16A / 250V AC** |
| **北美额定电流/电压** | **20A / 250V AC** | **20A / 250V AC** |
| **最高工作温度** | **70°C**（部分产品手册标称 **65°C**） | 同左 |
| **针脚配置** | **2 个电源针脚 + 1 个接地针脚**（2P+E） | 同左 |
| **标准归属** | IEC 60320（C19） | IEC 60320（C20） |

关于温度：多数标准和产品数据指向 **70°C**，例如 RS Online 的 C20 公头明确标注“最大温度额定值 70°C”，SCHURTER 的 C19/C20 目录也标注针脚温度 70°C。但部分成品电源线（如 RS PRO 的 C19-C20 线）标注的是 **65°C**，这通常是整线组件的认证限值，而非连接器本身的固有上限。**以 70°C 作为连接器标准参数、以具体产品标注作为实际使用依据**，是更稳妥的做法。

**北美 20A 的来源**：IEC 60320 标准对 C19/C20 的基准额定是 16A，而北美体系（UL/CSA）允许其在匹配 12AWG 线缆和相应插头时按 **20A/250VAC** 使用。这与 C13/C14 在北美可按 15A 使用是同一逻辑。

#### IDC 运维中的关键注意点

**接口是 16A/20A，不等于整线天然达到这个能力。** 这是 C19/C20 运维中最容易踩的坑。

C19/C20 接口标准支持 16A（国际）或 20A（北美），但整根电源线的实际安全载流量由**线径（AWG）** 和线缆认证决定。搜索结果清晰地展示了这一差异：

- **12AWG 线缆**：多条产品明确标注 12AWG 对应 **20A** 应用，例如 Tripp Lite 的 C20-C19 重型电源线（12AWG，20A，100–250V），以及 North America 20A 线缆的标准构造为 **3 × 12AWG** 电缆。
- **14AWG 线缆**：部分 C19-C20 成品线使用 14AWG，额定电流会**低于 20A**，例如 StarTech 的一款 C19-C20 线（14AWG）标注为 **250V/15A**。

因此，在高功率服务器上使用 C19/C20 时，**不能仅凭接口类型判断整线可承载 16A 或 20A**，必须核对线缆本体上的 AWG 和电流标识。对于接近 16A/20A 的负载，**12AWG 是更稳妥的选择**；14AWG 线缆应以其实际标称电流为准。

**与 C13/C14 的明确分工**：C13/C14 的国际基准是 **10A**，适用于绝大多数标准 1U/2U 服务器；C19/C20 的基准是 **16A（国际）/20A（北美）**，专门用于**电流需求超出 C13/C14 能力的设备**，典型包括大功率服务器、存储阵列、GPU/AI 服务器、刀片机框，以及 PDU 的输入或高功率输出端口。两者外形尺寸不同，**不可互插**。

**温度余量**：70°C 是连接器触点附近的允许温度上限。在高密度机柜中，如果电源线被捆扎在发热设备附近，或热通道温度偏高，实际工况可能逼近这一限值。C19/C20 承载的电流更大，触点发热量也相应更高，理线时应尽量避免将其长期置于高温区域或过度捆扎。
