## 电源线

### C13和C14

**C13 和 C14 是 IEC 60320 标准中一对配套使用、性能参数基本相同的电源接口**，可以理解为“**C13 是母头（输出端），C14 是公头（输入端）**”。C14 公头插在设备（如服务器电源、PDU）的插座上，C13 母头则连接电源线。

#### 核心性能参数

两者的电气和温度额定值在标准层面是一致的。

| 参数项 | **C13 连接器（母头/输出）** | **C14 输入口（公头/设备端）** |
| :--- | :--- | :--- |
| **国际额定电流/电压** | **10A / 250V AC** | **10A / 250V AC** |
| **北美额定电流/电压** | **15A / 250V AC** | **15A / 250V AC** |
| **最高工作温度** | **70°C** | **70°C** |
| **针脚配置** | **2 个电源针脚 + 1 个接地针脚**（2P+E） | 同左 |
| **标准归属** | IEC 60320（具体为 C13 连接器） | IEC 60320（具体为 C14 输入口） |

补充说明：部分产品数据表会将工作温度范围标为 **-25°C 至 +70°C**，但最关键的持续工作上限仍是 **70°C**。在北美，有时会利用 15A 的额定值，但这依赖于线缆和整个供电回路的匹配，**国际通用基准仍是 10A**。

### C19和C20

**C19 和 C20 是 IEC 60320 标准中一对配套使用、性能参数基本相同的电源接口**，与 C13/C14 的关系完全类似：**C19 是母头（电缆连接器），C20 是公头（设备输入口）**。C20 公头插在服务器电源或 PDU 的 C20 插座上，C19 母头则连接电源线的另一端。

#### 核心性能参数

两者的电气和温度额定值在标准层面一致，但北美存在一个更高的电流档位。

| 参数项 | **C19 连接器（母头/输出）** | **C20 输入口（公头/设备端）** |
| :--- | :--- | :--- |
| **国际额定电流/电压** | **16A / 250V AC** | **16A / 250V AC** |
| **北美额定电流/电压** | **20A / 250V AC** | **20A / 250V AC** |
| **最高工作温度** | **70°C**（部分产品手册标称 **65°C**） | 同左 |
| **针脚配置** | **2 个电源针脚 + 1 个接地针脚**（2P+E） | 同左 |
| **标准归属** | IEC 60320（C19） | IEC 60320（C20） |

关于温度：多数标准和产品数据指向 **70°C**，例如 RS Online 的 C20 公头明确标注“最大温度额定值 70°C”，SCHURTER 的 C19/C20 目录也标注针脚温度 70°C。但部分成品电源线（如 RS PRO 的 C19-C20 线）标注的是 **65°C**，这通常是整线组件的认证限值，而非连接器本身的固有上限。**以 70°C 作为连接器标准参数、以具体产品标注作为实际使用依据**，是更稳妥的做法。

**北美 20A 的来源**：IEC 60320 标准对 C19/C20 的基准额定是 16A，而北美体系（UL/CSA）允许其在匹配 12AWG 线缆和相应插头时按 **20A/250VAC** 使用。这与 C13/C14 在北美可按 15A 使用是同一逻辑。

## 双绞线

### 双绞线的线序

#### 定义

**568B 线序**是 **TIA/EIA-568B** 标准中规定的 RJ45 连接器（8P8C）接线顺序，是 IDC 和综合布线中最常用的以太网双绞线接线方式。它规定了 8 根芯线在 RJ45 水晶头/配线架中的颜色排列顺序。

#### 线序排列

面对 RJ45 水晶头的**金属触点面**（卡扣朝下、触点朝上），从左到右 8 个针脚的线序为：

| 针脚 | 线色 | 全称 | 功能（10/100M） | 功能（千兆） |
| :--- | :--- | :--- | :--- | :--- |
| **1** | **白橙** | 橙白 | TX+（发送+） | BI_DA+ |
| **2** | **橙** | 橙 | TX-（发送-） | BI_DA- |
| **3** | **白绿** | 绿白 | RX+（接收+） | BI_DB+ |
| **4** | **蓝** | 蓝 | 未用 | BI_DC+ |
| **5** | **白蓝** | 蓝白 | 未用 | BI_DC- |
| **6** | **绿** | 绿 | RX-（接收-） | BI_DB- |
| **7** | **白棕** | 棕白 | 未用 | BI_DD+ |
| **8** | **棕** | 棕 | 未用 | BI_DD- |

**记忆口诀**：**“白橙、橙、白绿、蓝、白蓝、绿、白棕、棕”**。注意第 4、5 针是蓝、白蓝，第 6 针才是绿——绿线不是紧跟在白绿后面，中间夹了蓝对，这是 568B 最容易接错的地方。

#### 与 568A 的区别

568A 和 568B 的区别仅在于**橙色对和绿色对的位置互换**：

| 针脚 | 568B | 568A |
| :--- | :--- | :--- |
| 1 | 白橙 | 白绿 |
| 2 | 橙 | 绿 |
| 3 | 白绿 | 白橙 |
| 4 | 蓝 | 蓝 |
| 5 | 白蓝 | 白蓝 |
| 6 | 绿 | 橙 |
| 7 | 白棕 | 白棕 |
| 8 | 棕 | 棕 |

蓝对和棕对的位置在两种标准中完全相同，只是橙对和绿对互换。

#### 直通线与交叉线

- **直通线（Straight-through）** ：两端**使用相同线序**（568B-568B 或 568A-568A）。用于不同类设备之间连接，如**服务器↔交换机**、**交换机↔路由器**。IDC 中绝大多数网线都是 568B 直通线。
- **交叉线（Crossover）** ：两端**使用不同线序**（568A-568B），即一端的 1/2 对应另一端的 3/6。用于同类设备之间连接，如**交换机↔交换机**（旧设备）、**服务器↔服务器**。现代交换机普遍支持 **Auto-MDIX**，能自动识别并适配直通/交叉，交叉线在 IDC 中已很少使用。

#### 百兆与千兆的线对使用差异

- **10/100M**：只使用 **1、2（发送）和 3、6（接收）** 两对线，4、5、7、8 空闲。
- **1000M（千兆）** ：**四对线全部使用**，1/2、3/6、4/5、7/8 分别承担双向收发，因此千兆必须 8 芯全接，且四对线都要按标准压接。
- **2.5G/5G/10G 短距离铜缆**：同样需要四对线全接，且对线缆等级（Cat5e/Cat6/Cat6a）和施工质量要求更高。

#### IDC 运维中的注意事项

- **同一链路两端线序必须一致**：直通线两端都按 568B 压接。如果一端 568B、另一端 568A，就变成了交叉线，在旧设备上可能导致不通。
- **4、5 针容易接错**：568B 中第 4、5 针是蓝、白蓝，第 6 针才是绿。接错会导致千兆降速或不通，百兆可能仍能工作，从而掩盖问题。
- **水晶头压接质量**：线芯必须顶到水晶头前端，外皮应压入水晶头尾部卡扣内，避免松动和串扰。压接后建议用**测线仪**逐芯验证 1–8 全通且顺序正确。
- **配线架与模块打线**：配线架和墙面模块通常标有 **A/B 色标**，打线时须与另一端水晶头线序一致。IDC 综合布线一般统一采用 **568B**。
- **线缆等级匹配**：Cat5e 可支持千兆，Cat6/Cat6a 支持更高带宽。线序正确但线缆等级不足，仍可能无法达到目标速率。
- **不要混用“白橙/橙白”叫法**：标准叫法是“白橙”“白绿”“白蓝”“白棕”，即**白在前、彩在后**，避免口头沟通时混淆。

#### 一句话总结

**568B 是 RJ45 最常用的接线标准，线序为“白橙、橙、白绿、蓝、白蓝、绿、白棕、棕”；它与 568A 的区别仅是橙对和绿对互换；IDC 中直通线两端统一按 568B 压接，千兆及以上必须 8 芯全接且四对线全部正确，第 4、5 针的蓝对和第 6 针的绿对是最容易接错的位置。**
