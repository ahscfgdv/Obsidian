#### A. 一句话定义与核心作用

`lsblk`（List Block Devices）是 Linux 系统中用来**以树状结构列出所有块设备**（如硬盘、分区、光驱、LVM 逻辑卷等）信息的命令。

与 `fdisk -l` 相比，`lsblk` 最大的优势是**直观**：它用树形结构展示了“哪块盘下面有几个分区、分区挂载在哪个目录”，而且普通用户无需 `sudo` 权限即可执行（**【只读/安全】**）。

---

#### B. 典型输出解析

在你的 CentOS 中直接输入 `lsblk`，典型输出如下：

```bash
[root@localhost ~]# lsblk

# 列名解释：
# NAME : 设备名
# MAJ:MIN : 主设备号:次设备号（内核识别硬件的编号）
# RM : 是否为可移动设备（1=是，如U盘/光驱；0=否）
# SIZE : 设备容量
# RO : 是否为只读（0=可读写，1=只读）
# TYPE : 设备类型（disk=物理磁盘，part=分区，rom=光驱，lvm=逻辑卷）
# MOUNTPOINT : 挂载点（如果为空，说明没有挂载，通常不能直接存取数据）

NAME            MAJ:MIN RM  SIZE RO TYPE MOUNTPOINT
sda               8:0    0   40G  0 disk 
├─sda1            8:1    0    1G  0 part /boot
└─sda2            8:2    0   39G  0 part 
  ├─centos-root 253:0    0   37G  0 lvm  /
  └─centos-swap 253:1    0    2G  0 lvm  [SWAP]
sr0              11:0    1 1024M  0 rom  
sdb               8:16   0    5G  0 disk 
└─sdb1            8:17   0    5G  0 part 
```

**结构说明**：
*   `sda` 是一块 40G 的物理磁盘（disk）。
*   它下面分了两个区（part）：`sda1` 和 `sda2`。
*   `sda2` 内部又跑了一个 LVM（逻辑卷管理），下面分出了 `root`（挂载到 `/`）和 `swap`（虚拟内存）。
*   `sr0` 是你之前问过的虚拟光驱。
*   `sdb` 是你刚用 `fdisk` 操作过的 5G 空盘，下面已经有了 `sdb1` 分区，但目前 `MOUNTPOINT` 为空，说明**尚未挂载，还不能存数据**。

#### C. 最常用的 5 个进阶用法（带代码块注释）

```bash
# ==========================================
# 1. 查看文件系统类型、UUID 和挂载状态（最常用）
# -f 代表 filesystem（文件系统）。包含 FSTYPE, UUID, MOUNTPOINT
# 【只读/安全】扩容、修改 fstab 前必查
# ==========================================
lsblk -f
# 输出示例：
# NAME   FSTYPE  LABEL   UUID                                 MOUNTPOINT
# sdb1   xfs             f3b1a2c4-1234-5678-90ab-cdef01234567 /mnt/data

# ==========================================
# 2. 显示完整设备路径（绝对路径）
# -p 代表 paths。通常输出的是 sdb1，加了 -p 会显示 /dev/sdb1
# 【只读/安全】写脚本或直接复制路径执行命令时非常实用
# ==========================================
lsblk -p
# 输出示例：
# /dev/sdb
# └─/dev/sdb1

# ==========================================
# 3. 只查看物理磁盘本身，不显示分区
# -d 代表 no dependencies（不显示依赖/子节点）
# 【只读/安全】快速盘点机器里插了几块物理盘
# ==========================================
lsblk -d
# 输出示例：
# NAME MAJ:MIN RM  SIZE RO TYPE MOUNTPOINT
# sda    8:0    0   40G  0 disk 
# sdb    8:16   0    5G  0 disk 

# ==========================================
# 4. 自定义要显示的列（过滤冗余信息）
# -o 代表 output。可以指定你想看的列，用逗号隔开
# 【只读/安全】只看盘名、大小和挂载点
# ==========================================
lsblk -o NAME,SIZE,MOUNTPOINT
# 输出示例：
# NAME   SIZE MOUNTPOINT
# sda     40G 
# ├─sda1   1G /boot
# ...

# ==========================================
# 5. 以字节为单位显示容量（排除换算误差）
# -b 代表 bytes
# 【只读/安全】排查分区对齐、计算精确容量时使用
# ==========================================
lsblk -b
```

#### D. IDC 运维排错场景（怎么用它）

1. **新盘没被识别**：插上新硬盘，运行 `lsblk`，如果列表里没出现（比如没有 `sdc`），说明是物理层问题（没插紧、背板线没接或没下电扫盘）。
2. **确认挂载关系**：做 RAID 或 LVM 时，看谁是谁的底层，树状图一目了然。
3. **扩容验证**：在云服务器或虚拟机扩容了磁盘容量，用 `lsblk` 刷新查看 `SIZE` 是否变大（如果没变，可能需要 `echo 1 > /sys/class/block/sda/device/rescan` 重新扫描）。
4. **坑点排查**：如果发现分区有 `sdb1` 但 `MOUNTPOINT` 是空的，说明系统并没有在使用它，此时你应该去检查 `/etc/fstab` 或者执行 `mount`。

#### E. 总结口诀
**“树状看盘用 lsblk，-f 查系统，-p 找路径，-d 找裸盘，MOUNTPOINT 为空就是没挂载。”**
