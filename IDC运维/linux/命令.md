## 附：mdadm 常用命令速记

创建 RAID（⚠️ 会清空成员盘数据，务必确认盘符）：

```shell
# 创建 RAID 0（6 块盘）
sudo mdadm --create /dev/md0 --level=0 --raid-devices=6 \
  /dev/sdb /dev/sdc /dev/sdd /dev/sde /dev/sdf /dev/sdg

# 创建 RAID 1（2 块盘镜像）
sudo mdadm --create /dev/md1 --level=1 --raid-devices=2 /dev/sdb /dev/sdc

# 查看阵列状态
cat /proc/mdstat
mdadm --detail /dev/md0

# 换盘：标记故障 → 移除 → 添加新盘
mdadm --manage /dev/md0 --fail /dev/sdb
mdadm --manage /dev/md0 --remove /dev/sdb
mdadm --manage /dev/md0 --add /dev/sdd
```

完整讲解见 [[mdadm]]。RAID 级别原理见 `[[硬盘#RAID]]`。

## 学习优先级建议（面试导向）

1. **第一梯队（必会）**：`[[top]]`、`[[df]]`、`[[ip命令]]`、`[[ethtool]]`、`[[ipmitool]]` —— 排障最常用。
2. **第二梯队（重点）**：`[[lscpu]]`、`[[dmidecode]]`、`[[lspci]]`、`[[smartctl]]` —— 硬件盘点和健康。
3. **第三梯队（加分）**：`[[mdadm]]`、`[[nmcli]]`、`[[lsscsi]]`、`[[常用命令速查]]` —— 展现深度。

理论背景对照：`[[CPU]]`、`[[内存]]`、`[[硬盘]]`、`[[主板]]`、`[[服务器]]`、`[[网卡]]`、`[[线缆]]`；操作规范 `[[SOP]]`、`[[运维红线]]`。
