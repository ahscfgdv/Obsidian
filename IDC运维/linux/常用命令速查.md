这份速查覆盖 IDC 运维面试和日常高频、但还没单独成篇的命令。每个命令单独成篇的见文末索引。

## 一、系统状态监控

| 命令 | 作用 | 常用形式 / 面试要点 |
| :--- | :--- | :--- |
| **free** | 查看内存使用 | `free -h`（人类可读）。重点看 **available**（真正可用），别被 used 吓到——buff/cache 是可回收缓存，呼应 `[[top]]` 的误区 |
| **uptime** | 查看运行时长与负载 | 输出的 load average 三个值分别对应 1/5/15 分钟，判断系统 trend；和 `[[top]]` 的负载一致 |
| **vmstat** | 虚拟内存/进程/IO 综合统计 | `vmstat 1`（每秒刷新）。看 `si/so`（swap 换入换出，持续非零=内存不足）、`wa`（IO 等待） |
| **iostat** | CPU 与磁盘 IO 统计 | `iostat -xz 1`。`%util` 接近 100% = 磁盘瓶颈；呼应 `[[top]]` 里 wa 高的排查 |
| **ps** | 查看进程快照 | `ps -ef` / `ps aux`；`ps -ef \| grep java` 找特定进程。区别于 `[[top]]` 的动态视图 |
| **pidstat** | 按进程统计资源 | `pidstat -u 1`（CPU）、`pidstat -d 1`（磁盘 IO），定位哪个进程在吃 IO |
| **sar** | 历史性能数据（sysstat） | `sar -u 1 3`（CPU），可查历史，适合事后回溯（需提前开启数据采集） |

## 二、磁盘与文件

| 命令 | 作用 | 常用形式 / 面试要点 |
| :--- | :--- | :--- |
| **du** | 统计目录占用空间 | `du -sh /var/log/*`（看哪个日志大）。区别于 `[[df]]`：`df` 看文件系统整体，`du` 遍历算目录 |
| **lsof** | 列出被进程打开的文件 | `lsof \| grep deleted`（找删了但被占用的文件，配合 `[[df]]` 的空间不释放场景）；`lsof -i :80`（看谁占用 80 端口） |
| **mount / umount** | 挂载/卸载文件系统 | `mount \| grep data` 看挂载；`[[lsblk]]` 看设备。**umount 前确认没进程在用**，否则报 target is busy |
| **dd** | 底层复制/写盘 | `dd if=/dev/zero of=/test bs=1M count=1024` 测写速。⚠️ **极度危险，写错 of= 会毁盘**，人称"数据毁灭者"（disk destroyer） |
| **rsync** | 高效增量同步 | `rsync -avz src/ dest/`，远程备份常用，支持断点续传、增量 |

## 三、网络排查

| 命令 | 作用 | 常用形式 / 面试要点 |
| :--- | :--- | :--- |
| **ss** | 查看端口/连接（netstat 的替代） | `ss -tlnp`（监听 TCP 端口及进程）、`ss -tan \| grep ESTAB`。面试说 ss 而非 netstat |
| **ping** | 测连通性 | `ping -c 4 <ip>`（发4个包）；通不通是网络排查第一刀 |
| **traceroute** | 追踪路由路径 | `traceroute <ip>`（Windows 是 tracert），定位在哪一跳断了 |
| **curl / wget** | 测 HTTP 访问 | `curl -I <url>`（只看响应头），测 web 服务是否正常、状态码 |
| **nc (netcat)** | 网络瑞士军刀 | `nc -zv <ip> <port>` 测端口通不通，比 telnet 更常用 |
| **tcpdump** | 抓包分析 | `tcpdump -i eth0 host <ip>`，抓包定位疑难网络问题，需 root |

> 网卡硬件层看 `[[ethtool]]`，IP/路由看 `[[ip命令]]`，持久配置看 `[[nmcli]]`。

## 四、文本处理三剑客（面试高频）

| 命令 | 作用 | 常用形式 |
| :--- | :--- | :--- |
| **grep** | 文本搜索过滤 | `grep -i "error" log`（忽略大小写）、`grep -v`（反向）、`grep -E`（正则）、`grep -c`（计数） |
| **sed** | 流编辑器（替换/删行） | `sed 's/old/new/g' file`（全局替换）、`sed -n '1,10p'`（打印1-10行） |
| **awk** | 按列处理文本 | `awk '{print $1}' file`（打印第一列）、`awk -F: '{print $1}' /etc/passwd`（指定分隔符） |
| **tail / head** | 看文件尾/头 | `tail -f log`（**实时跟踪日志，排障必备**）、`tail -100 log`（最后100行） |
| **find** | 查找文件 | `find / -name "*.log" -mtime +7`（找7天前的日志）、`-size +100M`（找大文件） |
| **wc** | 统计行数/字数 | `wc -l file`（数行数）、`grep error log \| wc -l`（统计错误出现次数） |

## 五、进程与服务管理

| 命令 | 作用 | 常用形式 / 面试要点 |
| :--- | :--- | :--- |
| **systemctl** | systemd 服务管理 | `systemctl status/start/stop/restart <服务>`、`systemctl enable <服务>`（开机自启）。现代 Linux 必会 |
| **kill / killall** | 终止进程 | `kill -9 <PID>` 强制杀（⚠️ 别乱杀系统进程，见 `[[top]]` 的危险操作）；`killall java` 按名杀 |
| **jobs / bg / fg** | 后台任务管理 | `cmd &` 放后台、`nohup cmd &` 退出终端仍运行、`jobs` 查看——远程长任务必备 |
| **crontab** | 定时任务 | `crontab -e` 编辑；格式 `分 时 日 月 周 命令`。巡检/备份脚本靠它 |

## 六、用户、权限与日志

| 命令 | 作用 | 常用形式 |
| :--- | :--- | :--- |
| **chmod / chown** | 改权限/属主 | `chmod +x script.sh`、`chown -R user:group /data`（递归改属主） |
| **sudo / su** | 提权/切换用户 | `sudo !!`（重复上条命令并提权，实用小技巧） |
| **journalctl** | 查 systemd 日志 | `journalctl -u sshd`（看某服务日志）、`journalctl -f`（实时跟踪）、`journalctl --since "2026-11-18"` |
| **dmesg** | 查内核日志 | `dmesg \| tail -50`、`dmesg -T`（带时间戳）。看硬件识别、驱动报错、OOM，配合 `[[lspci]]` |
| **last / who** | 查看登录记录 | `last`（谁何时登录过）、安全审计用 |

## 七、打包压缩与远程

| 命令 | 作用 | 常用形式 |
| :--- | :--- | :--- |
| **tar** | 打包/压缩 | `tar -czf a.tar.gz dir/`（打包 gzip）、`tar -xzf a.tar.gz`（解压） |
| **scp / sftp** | 远程传文件 | `scp file user@ip:/path`，基于 SSH，安全传输 |
| **ssh** | 远程登录 | `ssh user@ip`、`ssh -p 2222 user@ip`（指定端口） |
| **ssh-keygen / ssh-copy-id** | 免密登录 | 生成密钥对 + 分发公钥，批量运维必备 |
