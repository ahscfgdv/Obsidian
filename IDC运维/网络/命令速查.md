以下按**设备基础、接口、VLAN、路由、链路聚合、安全与维护**六个板块整理，覆盖华为交换机与路由器在VRP系统中最高频的配置场景。

---

### 🖥️ 设备基础与视图管理

| 操作 | 命令 | 说明 |
| :--- | :--- | :--- |
| 进入系统视图 | `system-view` | 从 `<用户视图>` 进入 `[系统视图]`，后续配置的前提 |
| 返回上一级/用户视图 | `quit` | 逐级退出，多次执行可回到 `<Huawei>` |
| 修改设备名 | `sysname <名称>` | 如 `sysname SW-Core-01`，立即反映在提示符中 |
| 查看当前配置 | `display current-configuration` | 日常排障首选，可简写 `dis cur` |
| **保存配置** | **`save`** | **不执行则重启后配置全部丢失** |
| 查看版本/硬件 | `display version` / `display device` | 版本、硬件模块、补丁信息 |
| 清除配置（恢复出厂） | `reset saved-configuration` | **慎用**，会清空启动配置并需重启生效 |
| 重启设备 | `reboot` | 执行前确认配置已保存 |


### 🔌 接口配置

| 操作 | 命令 | 说明 |
| :--- | :--- | :--- |
| 进入接口视图 | `interface GigabitEthernet 0/0/1` | 可简写 `int g0/0/1` |
| 配置 IP 地址 | `ip address 192.168.1.1 24` | 三层接口（路由器口、VLANIF、三层Eth-Trunk） |
| 开启/关闭接口 | `undo shutdown` / `shutdown` | 新接口默认可能是 `shutdown`，需手动开启 |
| 添加描述 | `description <描述>` | 强烈建议配置，如 `description To-Core-SW` |
| 查看接口简表 | `display interface brief` | 一眼看所有端口的 Up/Down、速率、双工 |
| 查看接口 IP 状态 | `display ip interface brief` | 重点关注协议状态是否 Up |


### 🏷️ VLAN 配置（交换机核心）

| 操作 | 命令 | 说明 |
| :--- | :--- | :--- |
| 创建单个/批量 VLAN | `vlan 10` / `vlan batch 10 20 30` | 批量创建可一次完成多个 |
| 配置 Access 口 | `port link-type access` → `port default vlan 10` | 连接终端（服务器/PC）的端口 |
| 配置 Trunk 口 | `port link-type trunk` → `port trunk allow-pass vlan 10 20` | 交换机级联口，需显式放行 VLAN |
| 放行全部 VLAN | `port trunk allow-pass vlan all` | 生产环境谨慎使用，按需放行 |
| 查看 VLAN 信息 | `display vlan` / `display port vlan` | 前者看 VLAN 列表，后者看端口归属 |
| 创建 VLANIF（SVI） | `interface Vlanif10` → `ip address ...` | 三层交换机实现 VLAN 间路由的接口 |


### 🧭 路由配置（路由器/三层交换机）

| 操作 | 命令 | 说明 |
| :--- | :--- | :--- |
| 配置静态路由 | `ip route-static <目标网段> <掩码> <下一跳>` | 如 `ip route-static 10.0.0.0 24 192.168.1.2` |
| 配置默认路由 | `ip route-static 0.0.0.0 0.0.0.0 <下一跳>` | 所有未知流量指向该地址 |
| 开启 OSPF 进程 | `ospf 1 router-id 1.1.1.1` | 进入 OSPF 视图，指定 Router ID |
| 宣告网段到 OSPF | `area 0` → `network 10.0.0.0 0.0.0.255` | 进入区域后宣告直连网段（通配符掩码） |
| 查看路由表 | `display ip routing-table` | 确认路由是否生效，优先级/度量是否合理 |


### 🔗 链路聚合（Eth-Trunk / LACP）

| 操作 | 命令 | 说明 |
| :--- | :--- | :--- |
| 创建聚合接口 | `interface Eth-Trunk 1` | 先创建逻辑聚合口 |
| 设置 LACP 模式 | `mode lacp-static` | 华为交换机默认是 manual（手工）模式，**对接 bond4 必须显式配 LACP** |
| 将物理口加入聚合组 | 进入物理接口 → `eth-trunk 1` | 逐个物理端口执行，成员口速率/双工需一致 |
| 查看聚合状态 | `display eth-trunk 1` | 检查成员口是否 Selected、LACP 是否协商成功 |


### 🔐 安全与管理（SSH / ACL / DHCP）

| 操作 | 命令 | 说明 |
| :--- | :--- | :--- |
| 开启 DHCP 服务 | `dhcp enable` | 全局使能后，地址池才能生效 |
| 创建 DHCP 地址池 | `ip pool <名称>` → `network ...` → `gateway-list ...` → `dns-list ...` | 为终端动态分配 IP |
| 接口调用 DHCP | 接口视图 → `dhcp select global` | 该接口下的终端从全局地址池获取 IP |
| 创建基础 ACL | `acl 2000` → `rule permit source 192.168.1.0 0.0.0.255` | 用于限制 SSH/SNMP 等管理访问来源 |
| SSH 结合 ACL 限制 | `ssh server acl 2000` | 仅允许 ACL 放行的源 IP 登录 SSH |
| 查看 ACL 配置 | `display acl all` | 确认规则匹配顺序和命中情况 |


### ⚠️ 速查要点

**保存是唯一持久化方式**：`save` 不执行，所有 `system-view` 下的配置在重启后全部归零。**Trunk 口必须显式放行 VLAN**，漏放行是跨交换机不通的最高频原因。**LACP 对接服务器 bond4 时**，交换机 `mode lacp-static` 与服务器 `mode=4` 必须双向匹配，否则聚合口无法 Selected。**OSPF 宣告用通配符掩码**（如 `0.0.0.255`），不是子网掩码。**静态路由下一跳必须可达**，否则路由条目可能在表中但流量被丢弃。
