# IDC机房IT运维主要工作内容

> 面试准备用：系统性梳理 IDC 机房 IT 运维的六大核心职责、标准作业流程与贯穿始终的操作红线。
> 关联笔记：[[SOP]]、[[运维红线]]、[[面试/服务器]]、[[数据中心]]



## 一句话总览

==IDC 机房 IT 运维，就是通过"巡检 + 操作 + 故障处理 + 应急 + 随工"，保障机房内服务器、网络设备等 IT 资产及其运行环境（供电、制冷、动环）持续、稳定、安全运行的现场技术工作。==

核心目标只有三个：**保在线（业务不中断）、保安全（人、设备、数据不出事）、保闭环（每件事有记录、有结论）**。

围绕简历中的实际职责，工作可归纳为六大块：

| 序号 | 工作模块 | 一句话概括 |
| :-- | :-- | :-- |
| 1 | 机房日常巡检 | 按规范看环境、看设备，发现异常第一时间上报 |
| 2 | 设备上下架与资产盘点 | 到货验收、上架理线、下架搬迁、账实核对 |
| 3 | 服务器故障处理 | 定位并更换硬件故障件，跟进厂商维修至恢复 |
| 4 | 网络故障处理 | 网线导通、联通检查与更换，处理硬件层网络故障 |
| 5 | 故障跟踪、上报与闭环 | 全程跟踪、及时通报、逐条结单 |
| 6 | 施工随工与应急处理 | 监督施工规范，突发掉电/温升/漏水时应急响应 |

---

## 一、机房日常巡检

### 巡检对象

- **环境侧**：温湿度、动环监控、UPS 电源、精密空调、消防与漏水情况。
- **设备侧**：浪潮 / 华为 / H3C 等服务器的运行状态、指示灯与 BMC 告警；网络设备的端口灯与链路状态。
- **机柜侧**：机柜是否单路掉电、PDU 供电是否正常、理线与标签是否规范。

### 巡检内容

- 检查机房温湿度是否在正常范围（冷通道一般 18~25℃），有无局部温升。
- 观察服务器、网络设备指示灯是否正常，有无告警、异响、异味。
- 核实机柜 A/B 双路供电是否正常，服务器是否单电源"裸奔"运行。
- 检查动环监控、UPS、空调运行参数，关注有无漏水、结露等异常。
- 封闭运行的设备不便打开组件时，可通过靠近**听声音**辅助判断风扇、硬盘状态。

### 异常发现与上报

==巡检的核心不是"看到了什么"，而是"发现了异常后怎么处理"==：

- 发现机柜掉电、服务器掉电、环境异常后，**第一时间反馈上报**并跟进处理。
- 发现网络和服务器设备故障且无法恢复时，立即通知上级领导，由相关领导协调资源处理。
- 对于未知的设备、现象、故障，出于信息安全需要，可向同公司在岗人员咨询，**不擅自发散操作**。

## 二、设备上下架与资产盘点

### 到货验收与上架

1. 提前根据上架工单中的上架表核对准备：U 位是否足够、PDU/电源线型号是否相符、接口与线缆数量是否充足、支架是否安装。
2. 服务器到货后开箱检查（有无磕碰异常、USB 接口有无外接存储设备）；上架前须用**墙电（市电）**开机测试，防止异常电源模块导致 PDU 短路掉电。
3. 检查无异常后由资产验收，再根据工单信息指导上架人员搬运至对应机架位上架。
4. 全程监督上架过程，防止厂商人员暴力操作、触碰在线设备及机柜 PDU。
5. 上架完成后由厂商工程师插电插线，**机房人员开机**（无法开机须通知装机负责人）。

### 下架与搬迁

1. 收到下架工单后按单操作（下架机器统一由工程师关机后方可操作）。
2. 核实四项基本信息后拔出电源线和网线，将机器向前推出 10 厘米并整理好线缆。
3. 拔出电源线后检查下架机柜中在线设备有无掉电现象。
4. 物流上门后指导下架人员搬运到货物交接区（轻拿轻放，禁止暴力搬运）。
5. 设备打包完成后在搬迁单签字确认，协助办理出门手续。

### 资产盘点与理线标签

- 协助硬盘拔除、设备下架及资产盘点，确保**台账与实物一致**。
- 综合布线要求：横平竖直、整齐划一；强电弱电分离、光纤铜缆分离；标签正确标识线路起止位置，距端口 5cm 处整齐粘贴。

## 三、服务器故障处理

### 涉及品牌与常见故障

- **主流品牌**：浪潮、华为、H3C 等服务器硬件结构、BIOS 设置与 RAID 阵列基础。
- **常见故障**：服务器无法开机 / 需重启、硬盘故障、内存不识别、电源故障、CPU / 主板故障。

### 诊断方法

- **看 BMC**：登录带外管理，查看硬件状态与 SEL 日志，定位告警部件；更换硬件后需清除 BMC SEL 日志。
- **最小化测试**：保留 1 个 CPU（CPU0）、1 根内存（插 CPU0 归属插槽）、1 个电源开机；能开机后再逐件加回，锁定故障硬件。
- **交叉测试**：如内存报错位置随内存转移 → 该内存故障；位置不变 → 交叉 CPU；仍不变 → 判断主板故障。

### 硬件更换通用 SOP

==所有更换类操作都遵循同一条主线，面试时按这条主线讲不会乱==：

**取件 → 双人复核 → 下架/断电 → 拆 → 装 → 测试 → 结单归库**

- **取件**：接单领取备件，核对 PN 与工单一致，观察外观有无损坏。
- **双人复核**：到达指定位置后双人复核，核实四项基本信息，粘贴防误操作标识牌与亚克力挡板。
- **下架/断电**：佩戴静电手环，按要求关机下架或断电。
- **拆**：核对拆下的故障件 SN 与工单一致；拆除前拍照留痕，防止无法还原。
- **装**：安装新备件，注意防呆标识对齐、硅脂涂抹规范。
- **测试**：开机后通过 BMC / BIOS 查看硬件状态是否正常，确认后结单。
- **结单归库**：记录新旧件 SN，故障件归还资产库。

> 具体流程见 [[SOP]]：CPU、主板、硬盘、内存、电源更换及交换机扩容/整机替换。

### 厂商维修跟进

- 涉及返修的设备，跟进厂商维修进度，直至设备恢复正常。
- 维修时（含厂商维修和自维修），进入包间只允许带入本包间需维修的存储介质。
- 严禁厂商单独执行关机、重启、插拔线缆等操作——**这些必须由现场运维执行**。

## 四、网络故障处理

- **网线导通测试**：对网线做导通测试、联通检查，判断线序与通断。
- **线缆更换**：更换故障网线、AOC 线缆等，处理日常网络故障。
- **少量布线**：承担机房内少量布线工作，遵循强弱电分离、光纤铜缆分离。
- **理线与标签规范**：线缆余长收敛在机柜内，走线桥架无多余线缆，标签标识清晰。

> 说明：运维工程师负责的是**硬件层面**的网络维护（线缆、端口、联通性），不涉及业务配置的下发与变更。

---

## 五、故障跟踪、上报与闭环

### 应急响应的"一二十五"原则

- **1 分钟**内响应告警并通知现场运维值班人员；
- **2 分钟**内通报故障内容至现场运维经理；
- **5 分钟**内同步进一步故障信息，联系不上经理则升级至 IT 运维总监；
- **10 分钟**内通告处理进度，直到事故处理完成。

### 工单闭环

- 所有操作**见单操作**：无工单（含飞书、邮件通知）的操作需书面文字发送 IT 运维组确认后再执行。
- 对机房内各类故障全程跟踪，及时上报进展；涉及链路问题配合运营商协调恢复。
- 确保每项故障**有记录、有结论、闭环完成**，结单时记录新旧件 SN 等信息。

## 六、机房应急处理

| 场景 | 关键动作 |
| :-- | :-- |
| 机柜单路掉电 | 1 分钟上报并赶赴现场 → 确认掉电范围与宕机情况 → 设施排查列头柜空开到 PDU 接线 → 临时 PDU 供电或试送电 → 逐台恢复设备 → 记录故障电源信息反馈客户 |
| 机房局部温升 | 测温枪检测冷通道温度 → 超 26℃ 协助设施降温（调低空调、开备用空调、设鼓风机）→ 检查盲板/热通道门/服务器风扇 → 两小时内持续跟进 |
| 机房漏水 | 1 分钟响应 → 2 分钟到场确认是否影响设备 → 5 分钟反馈现场可控性 → 10 分钟协助隔离排水 → 有设备宕机经确认后在 **PDU 端**做电源隔离（禁止设备端操作，防触电） |
| 批量设备宕机恢复 | 按楼分组、2 人一组双重复核四项信息 → 粘贴操作标签 → 逐台开机 → 楼长 10 分钟内统计进度并上报 |
| 误操作处理 | 安全情况下停止一切操作 → 立即如实上报主管 → 详细记录事件经过与关键信息，不隐瞒、不造假 |

## 七、施工随工

- 参与机房专项、零星施工的随工，现场监督施工规范，保障在线设备及机房环境安全。
- 保证施工人员人身安全，保证设备安全完好，禁止暴力施工。
- 涉及电力、登高、动火等作业需具备相应资质并经机房管理员允许。
- 施工区域与生产区域用隔离带、警示牌隔离；严禁施工人员触碰在线设备与线缆。
- 施工完成后及时清理现场，将垃圾、废料及个人工具带离机房。

## 八、贯穿始终的操作规范与红线

==这是面试的高频追问区，也是"能不能放心把机房交给你"的判断依据。==

### 见单操作与信息核对

- 操作前必须核实**四项基本信息**：机房包间号、机柜前（后）门编号、SN 号、U 位，与工单完全一致。
- 关键操作执行**双人复核**；单人操作需发单人确认，禁止一切账号相关操作。
- 在线操作（硬盘在线更换、电源更换、AOC 网线更换等）非业务确认禁止关机或重启。

### 安全红线（摘要）

- 禁止未经授权将 U 盘、移动硬盘等存储介质插入服务器 USB 接口。
- 禁止未经授权私自将笔记本接入服务器操作，或用网线/光纤直连设备。
- 禁止以任何方式登录硬盘操作系统、内存操作系统进行命令或查看操作。
- 严禁泄露机房信息（地址、机柜/PDU 型号、网络架构、IP、工单内容、SLA 等）。
- 严禁机房内饮食、吸烟、未经授权拍照录像；严禁携带背包包裹进入机房。
- 临时设备加电只能使用市电（墙电），禁止使用机柜 PDU。

> 完整规范见 [[运维红线]]。

## 面试话术小结

**Q：请介绍一下 IDC 机房运维的主要工作内容？**

> 我理解主要围绕六大块：一是机房日常巡检，看环境、看设备，发现异常第一时间上报；二是设备上下架和资产盘点，包括到货验收、上架理线、下架搬迁、账实核对；三是服务器故障处理，像硬盘、内存这些硬件故障，通过 BMC、最小化测试、交叉测试定位后更换，并跟进厂商维修；四是网络故障处理，主要做网线导通、联通检查和更换，处理硬件层网络问题；五是故障的跟踪上报和闭环，按"一二十五"原则响应，每件故障有记录有结论；六是施工随工和应急处理，监督施工规范，遇到掉电、温升、漏水能按流程响应。所有这些操作都必须见单操作、核实四项信息、双人复核，守住运维红线。

**高频追问方向**

- 巡检发现服务器掉电 / 机房温升，你怎么处理？ → 见"六、应急处理"
- 服务器上架前为什么要先用墙电开机测试？ → 防止异常电源模块导致 PDU 短路掉电
- 硬盘故障更换的完整流程？ → 见"三、硬件更换通用 SOP"
- 怎么防止误操作？ → 见单操作 + 四项信息核对 + 双人复核 + 防误操作标识
- BMC 带外网络不通怎么排查？ → 见 [[面试/服务器]]
